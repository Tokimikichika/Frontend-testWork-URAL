# Поиск автозапчастей Favorit Parts

Клиентское приложение на React и Redux Toolkit для двухэтапного поиска:

1. получение производителей по артикулу;
2. получение предложений и аналогов по артикулу и выбранному бренду.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

По умолчанию используется публичный демонстрационный ключ из документации.
При необходимости параметры можно переопределить через `.env` по примеру
`.env.example`. Не помещайте приватный клиентский ключ во frontend.

Проверки:

```bash
npm run lint
npm run test
npm run test:coverage
npm run check
```

`npm run check` последовательно запускает линтер, тесты и production-сборку.

## Интеграция API

Браузер напрямую обращается к HTTPS API Favorit Parts. API разрешает
cross-origin запросы, поэтому приложение работает на статическом GitHub Pages.
Адрес API и публичный демонстрационный ключ задаются через `VITE_API_URL` и
`VITE_FAVORIT_API_KEY`.

Цена берётся из конкретного склада (`warehouses.price`), как предписывает
документация API. Общая устаревшая цена товара не используется.

API-клиент ограничивает запрос десятью секундами и повторяет временные сетевые,
`429` и `5xx` ошибки два раза с увеличивающейся задержкой. Пустой ответ
считается отсутствием результатов, а некорректная структура отклоняется с
понятным сообщением пользователю.

## Архитектура

Проект разделён по слоям Feature-Sliced Design:

- `app` — инициализация приложения, store, providers и глобальные стили;
- `pages` — композиция страницы поиска;
- `widgets` — шапка, форма поиска и таблица предложений;
- `features` — сценарии поиска артикула и выбора производителя;
- `entities/part` — API, Redux model, selectors, helpers и constants детали;
- `shared` — общие конфигурации, constants, форматтеры и UI-компоненты.

Loader-компонент отображает загрузку производителей и предложений.
